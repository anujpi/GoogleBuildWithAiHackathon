\# Agricultural Intelligence Platform



An AI-powered agricultural decision intelligence platform combining:



\- Soil intelligence

\- Weather intelligence

\- Satellite/environmental intelligence

\- Crop intelligence

\- Supply forecasting

\- Demand forecasting

\- Market intelligence

\- Risk analysis

\- Scenario simulation

\- Regional supply-demand coordination



\## Project Structure



\- `frontend/` — React + TypeScript frontend

\- `backend/` — Spring Boot backend

\- `crop-map/` — India crop database (DES 2019-20) and a static district crop map (see `crop-map/README.md`)
